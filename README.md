SmartExamMonitor

This is a web application designed to monitor online exams. It helps track students, see their exam logs, and record exam details in real-time.

Features
* **Student Tracking:** View student details and their current exam status.
* **Logs & Events:** Track and record any events or actions during the exam.
* **Admin Dashboard:** A clean dashboard table to see everything clearly.

Technologies Used
* jsp and servlet and jdbc
* MySQL (Database to store data)
* Eclipse & Tomcat Server(Development tools)
